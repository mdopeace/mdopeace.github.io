Design decisions

Warm paper, square edges and hard shadows give this site its character. Shared 32, 40 and 48px controls, spacing tokens and consistent depth keep the parts working together. The components below power this page and the portfolio itself.

Try both themes, use your keyboard, and change the properties. Native controls, visible focus and reduced-motion support are part of the building blocks, alongside their appearance. Each example includes working React code and the thinking behind it.

Usage · React / TSX

"use client";

import { Button } from "@mdopeace/ui/Button";
import { FaHeart } from "react-icons/fa6";

export default function Example() {
  function handleClick() {
    console.info("Button activated");
  }

  return (
    <Button
      variant="primary"
      size="md"
      startIcon={<FaHeart />}
      onClick={handleClick}
    >
      Make something
    </Button>
  );
}

Complete example using the shared UI package.

Why this works

Every solid button uses the same 3px depth, whatever its size. Ghost actions stay flat. Hover compresses depth; pressing completes the movement.

Try it with a keyboard

Tab to the button, then activate it with Enter or Space. Disabled and loading states prevent activation.
